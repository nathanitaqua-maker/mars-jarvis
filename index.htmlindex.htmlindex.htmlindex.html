Setup Guide

1

Open the Google Cloud Console, create a project, and enable the Google Drive API.

2

Create an OAuth 2.0 Client ID (Web application). Add the exact URL this page is hosted at to Authorized JavaScript origins.

3

Create an API key and restrict it to the Drive API.

4

Paste both values here, click Save Credentials, then Sign in with Google. Jarvis requests the narrow drive.file scope — it can only see files it creates.

5

Jarvis will create MARS_JARVIS_DATA.json in your Drive on first sign-in and keep it in sync as your single source of truth. No servers, no databases — everything lives in your Drive.

Limitações reais do navegador

⚠ Segundo plano: uma aba do navegador não recebe áudio do microfone quando você troca de app ou minimiza a janela — isso é bloqueado pelo sistema, não é algo que uma página web possa contornar. Mantenha esta aba em foco para o Jarvis continuar ouvindo.

⚠ Abrir apps (Discord, Roblox, Spotify, Steam): um navegador nunca pode executar um programa diretamente. O que o Jarvis faz é chamar o "protocolo" do app (ex: discord://) — se o app estiver instalado, o sistema operacional abre uma confirmação; se não estiver, ou o navegador bloquear, o Jarvis abre a versão web como alternativa.
